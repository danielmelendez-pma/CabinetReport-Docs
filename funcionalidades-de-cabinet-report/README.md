# Funcionalidades de Cabinet Report

## Encuentra la herramienta para cada etapa del trabajo

Desde el acceso al proyecto hasta la entrega de los archivos de fabricación, Cabinet Report reúne herramientas para **organizar módulos y piezas, revisar la producción y preparar procesos de taller**.

Selecciona un objetivo para ir directamente a su guía. También puedes seguir el [Manual de usuario](../manual-de-usuario.md) si es tu primera vez.
