## Herramientas para trabajar desde la planificación hasta la fabricación

Cabinet Report integra distintos módulos para organizar los proyectos de mobiliario, preparar sus componentes y generar información de producción. Esta sección sirve como **mapa de funcionalidades**: elige el proceso que deseas conocer y accede a su página.

**Accesos rápidos:** [Empiezo por primera vez](../manual-de-usuario.md) · [Ya tengo un despiece](reporte-de-produccion.md) · [Necesito planificar cortes](optimizadores.md) · [Quiero preparar una cotización](costos-en-desarrollo.md).

## 3. Revisión, producción y optimización

### 🏭 [Reporte de producción](reporte-de-produccion.md)

Es el punto de concentración de módulos, piezas, materiales, cantos y datos técnicos previos a la fabricación. Incluye funciones de preparación, validación y generación de reportes.

### 🤖 [Revisor de Inteligencia Artificial](revisor-inteligencia-artificial.md)

Explica las revisiones automáticas y manuales, los hallazgos por gravedad, las decisiones y los límites del análisis asistido.

### 🗂️ [Auditoría RP y persistencia](auditoria-rp-persistencia.md)

Conoce cómo se vinculan las revisiones con la producción, el XML de auditoría, la recuperación y la trazabilidad económica.

{% hint style="info" %}
**Revisión asistida por inteligencia artificial:** en las versiones y configuraciones que la incorporen, sirve como apoyo para analizar posibles inconsistencias. Sus resultados requieren revisión y decisión del usuario; no garantizan la detección de todos los errores.
{% endhint %}

{% columns %}
{% column width="50%" %}
### ⚙️ [Optimizadores](optimizadores.md)

Conoce la optimización de tableros, perfiles y superficies, parámetros de corte y formatos exportables.

### 🛒 [Reporte de compras](reporte-de-compras.md)

Genera informes Excel para un ambiente o consolida compras de varios ambientes con trazabilidad.
{% endcolumn %}

{% column width="50%" %}
### 📦 [Orden de producción](orden-de-produccion.md)

Agrupa reportes RP en órdenes OP y produce archivos Excel vinculados a la fabricación.

### 🪵 [Stock de tableros](stock-de-tableros.md)

Consulta y administra el catálogo de tableros, sus fichas, precios registrados y permisos públicos o privados.
{% endcolumn %}
{% endcolumns %}
