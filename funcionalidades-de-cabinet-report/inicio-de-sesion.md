## El punto de entrada a tus proyectos

El inicio de sesión permite acceder a Cabinet Report con las credenciales y autorizaciones asignadas por la empresa. Su finalidad es **identificar a los usuarios habilitados** antes de consultar o preparar información de planificación y producción.

## Guía de acceso

1. **Abre Cabinet Report** en el equipo donde está instalado.
2. **Revisa los datos solicitados** en la pantalla de acceso; utiliza las credenciales de tu usuario y empresa.
3. **Completa el ingreso** mediante el control que presente tu versión.
4. **Comprueba la cuenta activa** antes de crear, consultar o modificar información de producción.

{% hint style="info" %}
**¿Todavía no tienes credenciales?** Solicítalas al administrador de tu empresa. La identificación del cliente y sus usuarios se explica en [Licencia de cliente](licencia-de-cliente.md).
{% endhint %}

## Si no puedes ingresar

- Verifica que las referencias introducidas sean las asignadas a tu cliente y usuario.
- Lee el mensaje que muestra la aplicación; distintos problemas pueden producir diferentes avisos.
- Si el acceso depende de un servicio externo, consulta su disponibilidad con el responsable técnico.
- Solicita asistencia antes de crear una cuenta alternativa o modificar una licencia.

{% hint style="warning" %}
**Alcance documentado.** Se confirma un control de acceso, pero la documentación disponible no permite precisar todos los botones, mecanismos de recuperación de credenciales ni una secuencia idéntica para todas las versiones. No compartas datos de licencia por medios no autorizados.
{% endhint %}
