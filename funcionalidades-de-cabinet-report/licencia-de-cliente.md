# Licencia de cliente

[🏠 Volver al portal principal de Cabinet Report](https://danielmelendez-pma.github.io/cabinet-report-partners/)

**CABINET REPORT · IDENTIFICACIÓN Y AUTORIZACIÓN**

## ¿Para qué sirve la licencia?

Cabinet Report utiliza información de licencia para **reconocer al cliente y a los usuarios autorizados** a utilizar la aplicación. Estas referencias no deben confundirse con el nombre del proyecto ni con los parámetros de un módulo.

<figure><img src="../.gitbook/assets/image (2) (1) (1) (1) (1) (1).png" alt="Captura existente de la interfaz de licencia"><figcaption><p>Identificación de licencia y usuario.</p></figcaption></figure>

## Datos suministrados por el administrador

| Dato | Propósito |
| --- | --- |
| **Cliente** | Nombre con el que la empresa o cliente figura en la licencia. |
| **Licencia cliente** | Código asignado para validar al cliente. |
| **Licencia usuario** | Código asociado a cada usuario habilitado dentro del cliente. |

{% hint style="info" %}
**Son referencias diferentes:** disponer de la licencia de cliente no significa que todos sus trabajadores queden automáticamente autorizados.
{% endhint %}

## Preparación para el primer acceso

1. **Solicita los datos** al administrador de licencias o responsable autorizado.
2. **Identifica el cliente correcto** al que pertenecerá el usuario.
3. **Introduce las referencias** únicamente en los campos que muestre la aplicación, cuando sean solicitados.
4. **Comprueba el resultado** antes de continuar al [inicio de sesión](inicio-de-sesion.md).
5. **Consulta al administrador** si algún código no se reconoce, corresponde a otro usuario o necesita actualización.

## Buenas prácticas

{% columns %}
{% column width="50%" %}
### 🛡️ Resguarda las referencias

No publiques códigos completos ni los compartas fuera de los canales autorizados por la empresa.

### 👥 Controla las asignaciones

Coordina las altas y bajas de usuarios con el administrador responsable.
{% endcolumn %}

{% column width="50%" %}
### 🧾 Confirma la identidad

Comprueba que cada usuario corresponda al cliente correcto antes de trabajar con proyectos.

### 🔎 Reporta incidencias

Conserva el mensaje de validación sin exponer las credenciales completas.
{% endcolumn %}
{% endcolumns %}
