# Licencia de Cliente

<figure><img src="../.gitbook/assets/image (2) (1) (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

El Administrador de Lcencias de Cabinet Report le suministrará las credenciales:

* **Cliente:** es el nombre de Cliente con el que se crea su licencia
* **Licencia Cliente:** es un codigo que le asigna el Administrador de Licencias, este codigo es para validar al cliente
* **Licencia Usuario:** es un código que le asigna el Administrador de Licencias, este codigo es para validar a cada usuario que el cliente suscriba

Con estas credenciales, la aplicación Cabinet Report valida que usted es un cliente y usuario autorizado para utilizar la aplicación.
