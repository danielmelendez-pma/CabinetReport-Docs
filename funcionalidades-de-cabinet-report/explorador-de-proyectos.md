## Encuentra información de tus trabajos

El Explorador de Proyectos ofrece un espacio para **visualizar y localizar proyectos registrados**. Resulta útil cuando necesitas identificar un trabajo por su nombre, el usuario que lo planificó o su número de reporte de producción (RP).

## Criterios de búsqueda descritos

| Filtro | Escenario de uso |
| --- | --- |
| **Nombre del proyecto** | Identificar un trabajo por su denominación. |
| **Usuario planificador** | Localizar trabajos asociados con quien realizó la planificación. |
| **Número de RP** | Consultar una referencia de producción conocida. |

## Recorrido de consulta

1. **Accede con un usuario autorizado** a Cabinet Report.
2. **Abre el Explorador de Proyectos** desde la opción disponible en tu versión.
3. **Elige el criterio de búsqueda** adecuado al dato que tengas.
4. **Revisa los resultados** y confirma que corresponden al trabajo esperado.
5. **Continúa con las operaciones habilitadas**; localizar un proyecto no implica necesariamente poder editarlo o importarlo.

{% hint style="info" %}
**Ejemplo:** si un responsable de producción recibe un número de RP, puede usarlo como referencia para localizar el proyecto y contrastar su identificación.
{% endhint %}

## Funciones descritas y capacidades futuras

{% columns %}
{% column width="50%" %}
### ✅ Consulta documentada

- Visualización de información de proyectos.
- Búsqueda por nombre, planificador o RP.
- Identificación de trabajos registrados.

Estas capacidades aparecen en la documentación original y deben comprobarse en la versión instalada.
{% endcolumn %}

{% column width="50%" %}
### 🕒 Funciones anunciadas

- Importar y abrir un proyecto directamente en otro equipo.
- Continuar trabajando con el proyecto desde otra computadora.
- Consultas específicas de almacén y compras sobre materiales y herrajes.

**No se presentan como funciones ya disponibles.**
{% endcolumn %}
{% endcolumns %}

{% hint style="warning" %}
**Consultar no equivale a edición remota.** La documentación de origen utilizaba expresiones de futuro para apertura entre equipos y consultas avanzadas. No se confirma aquí sincronización completa, colaboración multiusuario, transferencia automática de archivos ni acceso universal desde cualquier dispositivo.
{% endhint %}
