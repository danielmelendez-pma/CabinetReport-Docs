# Catálogo de Módulos

### 📦 Catálogo de Módulos – Cabinet Report

Cabinet Report pone a su disposición un **Catálogo Genérico de Módulos**, diseñado para agilizar la creación de proyectos y estandarizar la planificación de muebles de forma rápida, ordenada y flexible.

Desde este catálogo, el usuario puede **seleccionar módulos predefinidos**, configurar sus **medidas, materiales y cantos**, y agregarlos directamente a la **lista de producción**, evitando la creación manual pieza por pieza.

#### 🎯 ¿Qué permite el Catálogo de Módulos?

* Acceder a una **biblioteca visual de módulos genéricos**.
* Adaptar cada módulo a las **medidas reales del proyecto**.
* Definir **materiales de cajón, puertas y respaldo**.
* Ajustar y personalizar **cantos automáticamente o de forma manual**.
* Reutilizar módulos estandarizados para **ahorrar tiempo y reducir errores**.

***

### 🧭 Flujo de uso del Catálogo de Módulos

A continuación, se describe el proceso paso a paso para trabajar con el catálogo:

#### 1️⃣ Crear o abrir un archivo de producción

* Puede iniciar un proyecto nuevo o continuar trabajando sobre un archivo de producción existente.

#### 2️⃣ Activar el Catálogo Público

* Seleccione la opción **Catálogo Público** para acceder al catálogo genérico incluido en Cabinet Report.

#### 3️⃣ Seleccionar el catálogo

* Elija el catálogo que desea utilizar (por ejemplo, cocina base, cocina aérea, closets, etc.).

#### 4️⃣ Filtrar por Categoría

* Para facilitar la búsqueda, puede filtrar los módulos por **Categoría** (ejemplo: Cocina Base).

#### 5️⃣ Filtrar por Subcategoría

* Si desea un nivel mayor de precisión, seleccione una **Subcategoría** (ejemplo: Base 1 Puerta, Base 2 Puertas, Cajonera, etc.).

#### 6️⃣ Seleccionar el módulo

* El módulo puede seleccionarse:
  * Desde la **cinta visual superior**, o
  * Desde la **lista detallada de módulos**.

#### 7️⃣ Definir dimensiones

* Ingrese las medidas del módulo:
  * **Profundidad**
  * **Ancho**
  * **Alto**

Estas medidas se aplicarán automáticamente a todas las piezas que componen el módulo.

#### 8️⃣ Definir materiales

* Seleccione los materiales para:
  * **Cajón**
  * **Puertas**
  * **Respaldo**

Esto permite que cada módulo se adapte al material real del proyecto sin perder la lógica constructiva.

#### 9️⃣ Configurar cantos

* Puede:
  * Mantener los **nombres de cantos generados automáticamente**, o
  * Personalizarlos según el estándar de su taller o proveedor.

#### 🔁 Repetir el proceso

* Repita los pasos anteriores para agregar tantos módulos como necesite.
* Cada módulo se irá acumulando en la **lista de producción**, listo para optimización, revisión y exportación.

***

### ✅ Beneficio clave

El Catálogo de Módulos de Cabinet Report permite **trabajar con una base estándar**, pero con la flexibilidad necesaria para adaptarse a **cualquier proyecto real**, combinando rapidez, control y reducción de errores desde la etapa de planificación.
