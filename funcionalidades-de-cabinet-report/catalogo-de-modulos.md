# Catálogo de módulos

**CABINET REPORT · SELECCIÓN Y CONFIGURACIÓN TÉCNICA**

## Una estructura reutilizable para comenzar

El Catálogo de Módulos permite trabajar con **estructuras predefinidas** y ajustarlas a las necesidades de cada proyecto. Evita reconstruir manualmente módulos repetitivos, sin sustituir la responsabilidad de revisar las piezas antes de fabricar.

Planificadores de cocinas, clósets y otros muebles pueden partir de familias de módulos conocidas.

Catálogos, categorías y subcategorías ayudan a encontrar la estructura apropiada.

Las piezas resultantes pueden incorporarse al trabajo para su comprobación técnica posterior.

## Flujo práctico de trabajo

1. **Crea o abre el archivo** de producción correspondiente.
2. **Accede al Catálogo Público** o biblioteca genérica disponible en tu versión.
3. **Selecciona un catálogo**, una categoría y, cuando corresponda, una subcategoría.
4. **Elige el módulo** desde la cinta visual o el listado detallado.
5. **Define profundidad, ancho y alto** según el proyecto.
6. **Revisa los materiales** previstos para cajón, puertas y respaldo, si aplican.
7. **Comprueba los cantos** propuestos y sus posibles ajustes manuales.
8. **Incorpora el módulo a la lista de producción** con la opción disponible y verifica sus piezas.

## Ejemplo de aplicación

En una cocina, dos muebles de la misma familia pueden necesitar anchos diferentes. Selecciona la estructura adecuada para cada uno, modifica sus medidas y **revisa el despiece resultante**: materiales, espesores, cantos y cantidades.

## Lista de comprobación técnica

| Elemento | Qué revisar |
| --- | --- |
| **Dimensiones** | Profundidad, ancho, alto y unidades de trabajo. |
| **Fórmulas y variables** | Correspondencia con el tipo de módulo y las luces efectivas del cliente. |
| **Materiales** | Tableros y espesores apropiados para cada componente. |
| **Cantos** | Bordes que requieren canteo y denominaciones usadas. |
| **Piezas resultantes** | Medidas y cantidades antes de continuar a producción. |

{% hint style="warning" %}
**Un catálogo no garantiza ausencia de errores.** Las dimensiones de las piezas dependen de fórmulas y parámetros configurados; una definición incorrecta puede generar resultados inadecuados. Los catálogos propios y automatismos disponibles varían según versión y permisos.
{% endhint %}
