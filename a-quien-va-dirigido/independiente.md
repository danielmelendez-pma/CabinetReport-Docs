## Para quien combina varias responsabilidades

Si trabajas por cuenta propia, es habitual encargarte de las medidas, la planificación, la relación con el cliente y la coordinación del corte o canteo. **Cabinet Report puede ayudarte a reunir los datos técnicos** en lugar de repartirlos entre papeles, mensajes y hojas de cálculo.

### Retos cotidianos

- Transcribir medidas varias veces y mantenerlas actualizadas.
- Identificar qué piezas corresponden a cada módulo.
- Indicar correctamente materiales, espesores y lados de canteo.
- Entregar información comprensible a un proveedor externo.

## Un ejemplo de uso

1. **Organiza el proyecto:** identifica el cliente y el ambiente de trabajo.
2. **Prepara los módulos:** selecciona estructuras de un catálogo o utiliza módulos propios cuando estén configurados.
3. **Revisa el despiece:** confirma dimensiones, cantidades, materiales y cantos.
4. **Genera el reporte:** utiliza el formato de salida disponible y acuerda con el proveedor qué archivo necesita.

El proveedor puede recibir el documento sin tener que utilizar Cabinet Report, siempre que el formato entregado sea adecuado para su proceso.

## ¿Qué puedes ganar con este flujo?

**Menos transcripción manual:** centralizar la información permite evitar repetir algunos pasos.

**Comunicación más clara:** las piezas se presentan con datos técnicos estructurados.

**Mayor capacidad de revisión:** puedes comprobar el reporte antes de solicitar corte o canteo.

{% hint style="warning" %}
**Antes de enviar a producir:** contrasta el despiece con las medidas tomadas en obra, las condiciones de instalación y los requisitos del proveedor. El software no verifica por sí solo todas las condiciones físicas del proyecto y no garantiza la ausencia de errores.
{% endhint %}
